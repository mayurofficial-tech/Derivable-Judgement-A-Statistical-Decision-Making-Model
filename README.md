## 📌 Project Overview

This project focuses on applying **Inferential Statistics** techniques to a healthcare dataset using Python.

The objective is to analyze health-related variables, identify relationships between features, perform hypothesis testing, and draw meaningful conclusions from sample data.

The project demonstrates practical statistical concepts commonly used in **Data Science, Machine Learning, Healthcare Analytics, and Business Analytics**.

---

## 🎯 Project Objectives

* Analyze health-related data using statistical methods.
* Understand relationships between different health indicators.
* Perform hypothesis testing and statistical inference.
* Apply statistical techniques for data-driven decision making.
* Gain practical experience with real-world statistical analysis.

---

## 📊 Dataset Features

The dataset contains various health and lifestyle attributes:

| Feature            | Description                |
| ------------------ | -------------------------- |
| Age                | Age of individual          |
| Weight             | Body weight                |
| BMI                | Body Mass Index            |
| Blood Pressure     | Blood pressure measurement |
| Cholesterol Level  | Cholesterol indicator      |
| Glucose Level      | Blood glucose measurement  |
| Gender             | Male/Female                |
| Smoking Status     | Smoking behavior           |
| Exercise Frequency | Physical activity level    |
| Diabetes           | Diabetes status            |
| Hypertension       | Hypertension status        |

## 📈 Statistical Techniques Applied

### Confidence Interval

* Estimation of population parameters from sample data.

### Hypothesis Testing

* Statistical decision-making using sample evidence.

### One Sample T-Test

* Compare sample mean with population mean.

### Independent T-Test

* Compare means of two independent groups.

### Chi-Square Test

* Analyze relationships between categorical variables.

### One-Way ANOVA

* Compare means across multiple groups.

### Covariance Analysis

* Measure directional relationships between variables.

### Correlation Analysis

* Measure strength of relationships between variables.
